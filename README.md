# TrainWithNish

## Project name
TrainWithNish

## Year
2026

## Purpose
A personal fitness coaching web app that brings gym coaching tools into one place — protein tracking, PRs, workouts, habits, and interactive helpers — with all saved data stored in the browser via localStorage (no backend).

## Features
- Track protein goals and meals (optional USDA FoodData Central lookup)
- Log personal records and view a progress dashboard
- Interactive muscle map with training tips
- Cravings controller timer with motivation tips
- Workout planner with weekly split templates
- Challenge corner with checkable 30-day-style tasks
- Guides: exercises, motivation quotes, supplements, nutrition tips, and transformation stories
- Mobile-friendly homepage, navbar, and scroll-reveal animations

## Tech Stack used
- React 19, Vite 8, React Router 7
- Recharts, react-confetti
- Browser localStorage for persistence
- Optional USDA FoodData Central API
- ESLint
